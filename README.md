# LEXICO — 영어 단어 학습

브라우저에서 바로 쓰는 영어 단어 학습 페이지입니다. 설치 없이 `index.html`만 열면 됩니다.

## 시작하기

1. `index.html`을 더블클릭하거나 브라우저로 엽니다.
2. **학습 시작** 또는 **단어 목록 보기**를 선택합니다.

## 기능

| 모드 | 설명 |
|------|------|
| 플래시카드 | 카드를 탭해 뜻을 확인하고, 「알았어요 / 다시 볼래요」로 학습합니다. |
| 퀴즈 | 영어 단어의 한국어 뜻을 사지선다로 고릅니다. |
| 목록 | 전체 단어와 익힘 여부를 한눈에 봅니다. |

- 기본 단어 **20개** (품사 · 예문 포함)
- 익힌 단어는 브라우저 `localStorage`에 저장되어 다시 열어도 유지됩니다.

## 파일 구조

```
.
├── index.html   # 학습 페이지 (HTML / CSS / JS)
└── README.md
```
